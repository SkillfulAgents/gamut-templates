# Gamut Agent Templates

131 ready-to-run AI agent templates for [Gamut](https://www.gamut.so) — persistent AI agents that work like employees: they hold skills, memory, and schedules, and do real recurring work (chasing invoices, triaging tickets, drafting proposals, watching compliance deadlines...).

Each folder is a complete agent workspace (instructions, skills, config). Browse them with live docs, FAQs and one-click deploy at [gamut.so/agent-templates](https://www.gamut.so/agent-templates).

## How to use a template

1. **Easiest**: open the template's page on [gamut.so](https://www.gamut.so/agent-templates) and click *Use this template* — it deploys into a fresh Gamut agent.
2. **Manual**: copy a template folder into your own agent workspace and adapt the CLAUDE.md / skills to your stack.
